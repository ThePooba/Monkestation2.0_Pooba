monkestation/code/modules/job_xp/preferences/xp_handlers.dm

/proc/add_jobxpGives job xp to a client. If needs_job is TRUE it only works if they are currently playing that job.
/proc/remove_jobxpRemoves job xp from a client. This shouldn't normally ever be called unless you're sadistic.
/proc/add_jobxp_chanceSame as add_jobxp but only has a chance to give the xp, useful for super spammable stuff.
/proc/save_all_jobxpSaves the preferences of everyone that got job xp since their last save, including people that already disconnected.
