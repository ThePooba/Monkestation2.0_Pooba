bubble_icon_override
/datum/component/bubble_icon_override

A component that overrides the bubble_icon variable when equipped or implanted while having a simple priority system, so accessories have higher priority than organs, for example.

Vars

bubble_iconThe override to the default bubble icon for the atom
priorityThe priority of this bubble icon compared to others

Procs

get_bubble_iconGet the bubble icon with the highest priority from all instances of bubble_icon_override currently registered with the target.
get_bubble_icon_targetReturns the potential wearer/owner of the object when the component is un/registered to/from it
on_droppedUnregisters whoever dropped the item
on_equippedRegisters the wearer if the item was equipped in a slot it can be worn in
on_organ_implantedRegisters the mob the organ was implanted into
on_organ_removedUnregisters the mob the organ was removed from
register_ownerStarts overriding the bubble icon of the mob wearing or having this item/organ
return_bubble_iconPuts our bubble icon in the holder list if our priority is higher than the one already there
unregister_ownerStops overriding the bubble icon of the mob, going back to the next highest priority one or their default
